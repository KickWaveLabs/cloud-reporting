# Icons

Official Azure Architecture Icons (Microsoft), taken from the copies draw.io ships in
`jgraph/drawio/src/main/webapp/img/lib/azure2/` and rasterised to 256 px PNG with `rsvg-convert`.
`aa_deck_exec_v1.py` puts them on slide 2 of the corporate deck.

| File | Source SVG |
|---|---|
| `aks.png` | `containers/Kubernetes_Services.svg` |
| `container_apps.png` | `other/Container_App_Environments.svg` |
| `app_service.png` | `app_services/App_Services.svg` |
| `functions.png` | `compute/Function_Apps.svg` (shown only when `SHOW_FUNCTIONS` is True) |

Microsoft's terms for these icons: https://learn.microsoft.com/azure/architecture/icons/
